pandas and DataFrames

pandas is Python’s library for tables, and a table in pandas is a DataFrame.

Source: UBC Master of Data Science, Programming in Python for Data Science

  • Named columns, and rows labelled by an index
  • One column on its own: a Series
  • Every pandas command works on whole columns at once

Five Operations

Almost every data question needs only five operations, and you have done all five in Tableau:

Operation What it does In Tableau In pandas
Selection keeps columns the fields you drag in insta[["format", "reach"]]
Reduction keeps rows the Filters shelf insta[insta["format"] == "reel"]
Extension adds a column a calculated field insta["rate"] = insta["likes"] / insta["reach"]
Aggregation a row per group SUM by a dimension insta.groupby("format")["reach"].sum()
Combination joins two tables a relationship or a join pd.merge(posts, ads, on="post_id", how="left")

Today, a first look at the table, then the first three operations, one section each. Lecture 8 does the last two, and Lecture 9 draws the results.

Reading a CSV File

A CSV file is a table written as text (Lecture 2): names on the first line, one row per line, commas between the values. The start of insta-data.csv:

post_id,posted_at,format,product_line,theme,campaign,is_paid,...
LR0001,2025-01-08 20:00:00,reel,Knitwear,styling,,False,...
LR0002,2025-01-08 12:00:00,reel,Knitwear,customer,,False,...
insta = pd.read_csv("insta-data.csv")    # first cell, after the import
  • pd.read_csv() reads the text into a DataFrame, with a type for each column. The file’s name goes between quotes, spelt as in the Files panel
  • insta = stores the table under a name of your choice. Nothing is shown: = stores, it does not display
  • Semicolon files: pd.read_csv("file.csv", sep=";"). Excel files: pd.read_excel("file.xlsx")

With or Without Brackets

Without: an attribute, a value the table already holds. You only read it.

insta.shape      # its size
insta.columns    # its column names

With brackets, it fails:

insta.shape()
TypeError: 'tuple' object is not callable

With: a method, a function of the table (Lecture 6). The brackets run it, and hold its options.

insta.head(3)    # show 3 rows
insta.info()     # describe each column

Without brackets, nothing runs:

insta.info
<bound method DataFrame.info of ...>

Has or does? What the table has, its size or its names: no brackets. What it does, show, describe, count or sort: brackets.

3. Filtering and Sorting Rows

Filtering Rows

insta[insta["format"] == "reel"].head(3)
post_id posted_at format ... spend_eur attributed_purchases attributed_revenue_eur
0 LR0001 2025-01-08 20:00:00 reel ... 0.0 0 0.0
1 LR0002 2025-01-08 12:00:00 reel ... 0.0 0 0.0
6 LR0007 2025-01-18 17:00:00 reel ... 0.0 0 0.0

3 rows × 26 columns

  • insta["format"] == "reel" gives True or False for every row; the square brackets around it keep the rows that are True
  • The numbers on the left are the index: each row keeps its label, here 0, 1 and 6
  • Text goes in quotes, "reel"; numbers do not: insta["reach"] > 50000

Comparisons

Operator Means
== exactly equal
!= not equal
> and >= greater than, greater than or equal
< and <= less than, less than or equal

The easiest mistake to make is one = instead of two:

insta[insta["format"] = "reel"]
SyntaxError: cannot assign to subscript here. Maybe you meant '==' instead of '='?

= stores a value, == compares two. Python stops, and suggests the fix.

What & Does

Source: UBC Master of Data Science, Programming in Python for Data Science

Each condition keeps some rows; & keeps only the rows both conditions keep.

Two Conditions at Once

big_reels = insta[(insta["format"] == "reel") & (insta["reach"] > 50000)]
reels_or_big = insta[(insta["format"] == "reel") | (insta["reach"] > 50000)]
print(len(big_reels), len(reels_or_big))
3 206
  • & keeps the rows where both conditions are True: 3 reels above 50,000 accounts
  • | keeps the rows where either is: the 203 reels, plus the 3 other posts above 50,000
  • Each condition in its own round brackets: without them, Python reads "reel" & insta["reach"] first, and fails. The words and and or do not work on columns
  • len() of a table counts its rows

Several Values at Once

two_lines = insta[insta["product_line"].isin(["Denim", "Knitwear"])]
low_reach = insta[insta["reach"].between(1000, 2000)]
print(len(two_lines), len(low_reach))
171 54
  • isin([...]) keeps the rows whose value is any of a list: 171 Denim or Knitwear posts
  • between(a, b) keeps the values from a to b, both included: 54 posts reached 1,000 to 2,000 accounts
  • Each replaces a chain of conditions: between(1000, 2000) is (insta["reach"] >= 1000) & (insta["reach"] <= 2000)

4. Creating Columns and Saving Tables

A New Column

insta["engagements"] = insta["likes"] + insta["comments"] + insta["saves"] + insta["shares"]
insta[["post_id", "likes", "comments", "saves", "shares", "engagements"]].head(3)
post_id likes comments saves shares engagements
0 LR0001 38 0 5 2 45
1 LR0002 100 2 15 5 122
2 LR0003 674 14 88 41 817
  • A calculated field, as in Tableau: the formula runs on every row at once, with no loop
  • A new name on the left creates a column, at the end of the table; an existing name replaces it

A Rate, Rounded for the Reader

insta["engagement_rate"] = insta["engagements"] / insta["reach"] * 100
insta[["post_id", "engagements", "reach", "engagement_rate"]].head(3).round(1)
post_id engagements reach engagement_rate
0 LR0001 45 735 6.1
1 LR0002 122 2647 4.6
2 LR0003 817 10393 7.9
  • +, -, * and / work between columns, or with a number: * 100 gives a percentage
  • .round(1) rounds what you show, to one decimal, as Lecture 6’s round(x, 1) rounds one number
  • insta keeps every digit, for the calculations that come next

Saving a Table

paid = insta[insta["is_paid"] == True]
paid.to_csv("paid-posts.csv", index=False)
  • .to_csv() writes the table as a file in the Files panel: right-click / ⌃ Control + click on it → Download
  • index=False stops pandas writing its row numbers as an extra column
  • Like an uploaded file, a saved file is deleted with the runtime: download it before you leave
